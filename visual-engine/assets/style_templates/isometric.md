# Style: isometric

## Visual Fingerprint
3D vector illustration in axonometric projection (typically 30° angles, no vanishing point perspective). Clean geometry, soft gradient shading, slight ambient occlusion. Feels like a friendly technical diagram crossed with a video game asset.

## Reference Phrasing for Gemini
Lead the prompt with one of:

- "Isometric 3D illustration, axonometric projection at 30 degrees, clean vector aesthetic with soft gradient shading."
- "Modern isometric tech illustration in the style of contemporary SaaS marketing pages, clean geometry, subtle shadows."
- "Axonometric vector scene, low-poly 3D, friendly approachable tech aesthetic."

## Subject Treatment
- Buildings, devices, infrastructure, abstract data visualizations: all native to this style.
- Human figures, if included, should be stylized and small relative to the scene.
- Each object should be a clean geometric shape; avoid complex organic forms.
- Multiple objects can be arranged in a "scene" rather than a single subject.

## Composition Notes
Pairs naturally with: `birds-eye-view` (almost native), `centered-subject`, `pattern-repetition`, `diagonal-motion`.

Avoid `silhouette` and `frame-within-frame` — these fight the style.

## Palette Pairings
Best with: `cold-architecture`, `electric-dusk`, `soft-laboratory`, `terminal-green`.
Isometric works best with 3-4 distinct colors, not gradients between many. Be explicit: "Use only these four colors."

## Things to Avoid in Prompts
- "Photorealistic" — contradicts the style
- "Hand-drawn" or "sketchy" — contradicts the style
- Adding perspective or vanishing point — breaks the isometric grid

## Example Prompt Skeleton

```
Isometric 3D illustration, axonometric projection at 30 degrees, clean vector aesthetic with soft gradient shading. Scene depicts: [SPECIFIC OBJECTS arranged in a SPECIFIC SPATIAL RELATIONSHIP — e.g. "three glowing server racks connected by orange cable conduits to a central hub representing a cost dashboard"]. [COMPOSITION]. Palette restricted to: [4 colors with hex codes]. Soft top-down ambient lighting, subtle ground shadow. 16:9 aspect ratio, friendly tech illustration aesthetic. No text, no logos, no humans unless specified.
```

## Best For
- Technical tutorials and how-to posts
- Architecture explanations
- Tool comparisons
- Process or pipeline visualizations
- "Behind the scenes of how X works" posts
